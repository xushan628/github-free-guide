## 这三个 skill 的边界

- **都要接自己的模型**：skill 只是提示词与流程，没有模型跑不起来。
- **book-to-skill 处理书籍要看版权**：把整本 PDF 喂进去做 skill，自己用可以，**对外分发就是侵权**；商业书籍尤其别碰。
- **jev 这类"读意图"的助手**：输出是概率判断，别拿它当读心术；涉及重要沟通（谈判、职场）仍要自己判断。
- **狗头军师是决策辅助，不是专业意见**：它内置的心理/法律内容来自社区整理，**不构成心理咨询或法律建议**；亲密关系、婚姻财产这类问题别把 AI 输出当定论。
- **公考真题库是 skill，不是题库网站**：装进支持 `SKILL.md` 的宿主（如豆包工作模式）才能用；考点体系**沿用「花生十三」课程**，那部分内容的版权归原作者，**自用可以、别二次分发**。
- **旅行路书** 依赖实时联网查询，节假日信息变化快，出发前复核订票/营业时间。

## 这批的三个边界

- **Hypit 这类"复刻爆款"工具**：本质是拆解他人视频再生成同构内容，**素材版权与平台原创判定都在灰色地带**（用了别人的镜头/文案可能被判搬运）；许可证是 NOASSERTION，商用前自己读 LICENSE。
- **OmniRoute 这类"免费额度聚合"**：本质是替你轮询多家免费额度，**各家条款与风控各不相同**，账号可能因为异常调用被限；模型质量也参差，别把生产任务压上去。
- **DS Bot 是社区项目，非 DeepSeek 官方**（视频里也这么写）：跑在你本机、花自己的额度，多 bot 协作会显著放大 token 消耗。
- **career-ops / promptfoo 都 MIT**，但 career-ops 自动投递同样踩招聘平台协议；promptfoo 的红队功能只对自己的系统用。

## 这批的边界

- **Deep-Live-Cam 是换脸工具**：AGPL-3.0，技术本身开源，但**未授权使用他人肖像制作用于冒充、诈骗或色情内容，可能构成违法**；它的 README 也写了使用须获同意。别拿它做"虚拟主播"以外的事。
- **elephant-goldfish-model**：Google 的设计/评审"双角色"思路，适合让 AI 自己挑自己的毛病，但不是"评审一定更对"。
- **anthropics/skills** 是官方技能集合，GitHub 标 NOASSERTION，**引用到商业产品前逐个看子目录的许可**。

## 这批的边界

- **Mika / Cactus 是端侧 agent**：要在手机上开无障碍/后台权限，等于把手机操作权交给模型，先在小号设备上试。
- **reverse-skill 只写"授权测试"**：未授权对他人系统做逆向/渗透是违法的，这条底线不能模糊。
- **TencentDB Agent Memory** 是团队级记忆，会把对话/代码图谱集中存储，**权限与脱敏**要提前设计。
- **Unsloth 要显卡**：本地训练省的是云费，不是不花钱（电费 + 显卡）。

## 配音/写作类的边界

- **ChatTTS 是 AGPL-3.0**：生成的音频商用前看清条款；做口播时**别克隆他人音色**。
- **whisper 转写**：上传前想清楚素材是否含他人隐私/未授权内容。
- **webnovel-writer 只是辅助**：长篇的质量取决于设定与结构，AI 负责"不忘"，不负责"好看"。

## 小说 skill 只需装一个全包

那套「小说 10 个 Skill」其实来自同一个仓库 —— **`zenstory-ai/oh-story-claudecode`**（★8.8k · MIT · 14 个 skill）。
不用逐个装：`npx skills add zenstory-ai/oh-story-claudecode -y -g` 一次性装全，日常写书 5 个命令足够：

| 命令 | 干什么 |
|---|---|
| `setup` | 初始化项目（设定、大纲、追踪目录） |
| `long-write` | 长篇连载推进 |
| `short-write` | 短篇成稿 |
| `deslop` | 去 AI 味 |
| `review` | 审核一致性 / 逻辑 / 断章 |

它用**文件系统当记忆**（追踪数据在 `追踪/_tracking-state.json`），所以长篇不容易"忘设定"；适配 Claude Code、Codex CLI、OpenCode 等 7 款 agent。

## 用之前要知道的

- **许可证不是都干净**：`VoiceStudio` 是 **AGPL-3.0**（改完对外提供网络服务要开源），`awesome-dsh-plugin` 的 CC0 只覆盖清单、不覆盖插件代码。
- **agent 产出要复核**：Archify 的架构图是从代码推断的，画错的时候同样好看；scientific-agent-skills 不能改变"模型会编参考文献"，投稿前每处引用回源核对。
- **声音克隆涉人格权**：VoiceStudio 克隆他人声音必须拿到书面授权。
- **研究原型别上生产**：`dsh-superagent-prototype` 名字里就写着 prototype。
- 插件/技能类项目通常要接自己的 LLM（云端 API 或本地 Ollama）才有内容。
