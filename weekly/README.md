# 10 · GitHub 一周热点（追更收录）

GitHub 每周都会冒出几个"这个有点意思"的项目。这一章按**期**归档，把抖音「Github一周热点」里提到的项目落到具体仓库，并标注**核实过的**星数、许可证和语言 —— 不转述视频里的评价，只写仓库自己说的事实。

- 每期一个子目录：`weekly/<期号>/`
- 每期三样东西：`README.md`（逐项说明）、`projects.json`（机器可读）、索引表里加一行
- 选仓库的标准：名字对得上 + 能确认是同一类东西 + 仓库还活着（未归档）

## 怎么用这一章

1. 先看 [137/README.md](137/README.md) 的表格，判断有没有你要的；
2. 想看机器可读版本（做导航站、做爬虫、做对比表）：`137/projects.json`；
3. 收录不代表推荐 —— 星数高只说明关注度，**许可证和仓库活跃度**才是能不能用的关键，两列都给了。
