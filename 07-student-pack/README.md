# 07 · GitHub Student Developer Pack：学生身份的"官方外挂"

视频里的"官方福利"就是它。**有学生身份就是最大的一次性收益**：几十家商业工具免费或大额折扣。

入口：**<https://education.github.com/pack>**

---

## 申请流程（10 分钟）

1. 注册 GitHub 账号，进 `Settings → Billing and plans → Education benefits`，或直接打开上面的 Pack 页面点 `Get your pack`
2. 填写：
   - 学校名称（要和证明文件上的**完全一致**）
   - 预计毕业时间
   - 一段简短说明（"我在读 XX 专业，想用这些工具做课程项目/毕业设计"）
3. 上传证明（任选其一，**必须能看清姓名和学校**）：
   - 学生证（含当前学期注册章/有效期）
   - 在读证明 / 录取通知书
   - 学费缴纳凭证
   - 官方成绩单
4. 提交后等审核，通常 **几天到两周**。被拒可以补材料重申，没有次数惩罚。

> **教育邮箱（.edu / .edu.cn）不是必须的**，但学校邮箱能显著加快审核。没有的话，用带学校抬头的在读证明也能过。

## 学生认证之后还能薅什么

- **Copilot 免费**：`Settings → Copilot` 开启，学生身份自动识别（有时需重新验证）
- **GitHub Pro 私有仓库 + Pages**：私有仓库也能开 Pages 了
- **Actions 分钟数提升**：Pro 账号私有仓库 3,000 分钟/月
- **Codespaces 额度提升**：Pro 账号 180 core-hours/月

---

## 坑

1. **毕业就失效**：认证有有效期（一般 2 年或到毕业）。到期后 Copilot、Pro 会掉回免费档，别把生产环境建在"学生价"上。
2. **别买"学生认证代办"**：GitHub 会封号，且违反服务条款。自己传材料 10 分钟的事。
3. **材料造假 = 永封**：伪造学生证被查出来，账号直接封，连带你的代码和仓库。
4. **同一个身份只能一份**：开小号重复领会被风控识别。
5. **权益要主动领**：Pack 里很多是"优惠码"，需要分别点进去兑换，不会自动到账。

---

## 不是学生怎么办

- **教师**：`GitHub Education` 也有 Teacher 通道，权益类似。
- **开源维护者**：部分项目（如 Copilot 对热门开源维护者）有免费额度。
- **纯白嫖路线**：本仓库第 1–6 章的所有内容都不需要学生身份，照样能免费用。
