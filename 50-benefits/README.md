## 建议的阅读顺序

**先看 [limits/](limits/README.md)，再去薅权益。**

原因很实际：额度表和坑位决定了你"能不能长期白嫖"，而学生包是有期限的（毕业失效）。先搞清楚边界，再去申请，不容易把生产环境建在会过期的东西上。

## 一句话记住

- 学生包**不是永久的**，毕业掉档；
- Actions 私有仓库**按时长计费**，公开仓库不限但滥用会被限流；
- `cron` 一律 UTC，北京时间要减 8 小时；
- **没有 LICENSE 文件 = 不能商用**，这是版权法默认规则。
