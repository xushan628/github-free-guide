## 下载器怎么选：Gopeed vs Motrix

| | Gopeed | Motrix |
|---|---|---|
| 许可证 | GPL-3.0 | NOASSERTION（识别不出） |
| 技术栈 | Go + Flutter | Electron |
| 协议 | HTTP / BT / 磁力 / **ed2k** | HTTP / BT / 磁力 |
| 浏览器扩展 | 有 | 有 |

两个都能接磁力和种子；要 ed2k 选 Gopeed，要界面简单选 Motrix。

**关于"网盘提速"（视频里最吸引人的那句，得说清楚）**：
- 那个"百度网盘扩展"是**第三方**的，不在这两个下载器仓库里；这类扩展里最有名的 `acgotaku/BaiduExporter` **2021 年就停更了**（★214），网盘接口早变过，能不能用要自己试；
- 绕过限速通常违反网盘用户协议，**限速/封禁风险自担**；
- 别把"能下网盘"当成选择下载器的理由。

## 这四个的边界（都挺实用，但别踩线）

- **android-ad-cleaner**：走的是系统/App 自带开关 + 组件挂起，**不 root、可还原**，这点比破解类干净；但**厂商 OTA 一升级就可能失效**，别指望一劳永逸，也别拿它当"绕过一切广告"的承诺。
- **DiPlay**：本质是把 iPhone 的 CarPlay 协议在安卓车机上实现，**涉及车机安装与授权**；行车中操作有安全风险，CarPlay 授权本身存在灰色地带，自用自行评估。
- **OldAlmanac**：仓库**没有 LICENSE 文件** → 按默认版权规则，**不能商用、不能二次分发**，自己看、自己打印可以。
- **TypeWords**：GPL-3.0，自己用没问题，改了分发要开源。

## 这四个的边界

- **LinkSwift 是"打补丁"类工具**：靠匹配网盘页面结构取直链，**网盘一改接口就失效**，作者更新跟不上时别惊讶；AGPL-3.0，改了分发要开源。
- **MoeKoeMusic 是第三方客户端**：用的是非官方接口，**账号被风控/封禁的风险自担**，重要账号别登。
- **Piik** 走 P2P + 可选自建服务端，邀请链接谁拿到谁能进，**别把链接发到公开群**。
- **ZTools** 是 uTools 的开源替代，插件生态比原版小，迁移前先确认你要的插件有没有。

## 光猫工具只对自有设备用

`ung220z-tool` 的边界必须先讲清楚：
- **只用于你自己名下的光猫**——对运营商或他人设备做同样操作属于入侵；
- 提取超管、改桥接会**触碰运营商服务条款**，部分省份会远程下发配置覆盖你的设置，甚至影响保修与报障；
- 属提权类工具，**固件一升级就可能失效**；操作前把原配置截图存好，改坏了能回退。
- MIT 许可，代码可读，建议先看源码再跑。

## TVBox 类项目的版权红线（比功能重要）

`TVBox Desktop` 这类客户端的"内置播放源"，绝大多数是**未经授权的影视聚合源**：

- 项目本身是 MIT、代码干净，但**播放源不是项目提供的**，是第三方接口；
- 在国内，**提供或使用盗版影视聚合源属于著作权侵权**，近年已有大量判例（含使用者被诉的案例）；
- 所以：**可以当技术项目研究，不建议作为日常观影主力**。想合法看片，还是走正版平台。

同理，仓库里有多个同名分支（`tengdechun/tvbox-desktop` ★16、`LanLanff/FlyTV` ★34），收录的是 ★811 那个；换分支前先看它的源从哪来。

## 自动投简历：风险比效率大

`get_jobs` 这类工具**明确违反招聘平台的用户协议**，用之前必须知道：

- **封号是常态不是意外**：BOSS / 猎聘 / 智联都禁止脚本自动化，被判定后账号会被限制甚至封停，影响后续正常求职；
- **许可证是 NOASSERTION**（GitHub 识别不出）→ 商用前自己读 LICENSE；
- **海投反而降低命中率**：同一份简历投 500 家，不如按 JD 精投 20 家；自动投递只解决"投得多"，不解决"匹配"；
- 平台一旦升级风控（验证码、行为检测），脚本会立刻失效。

**国际同类可作参照**（英文岗位更适用）：[career-ops-hq/career-ops](https://github.com/career-ops-hq/career-ops)（MIT · ★83.8k）、[feder-cr/Jobs_Applier_AI_Agent](https://github.com/feder-cr/Jobs_Applier_AI_Agent)（MIT · ★32.6k）。

## 这批的边界

- **Immich / Odoo 是"自己管数据"的重型服务**：部署前先想清楚备份与权限，Immich 的相册一旦暴露公网就是全家照片；Odoo 的社区版与商业版功能/许可不同，商用前看官网条款（GitHub 上识别为 NOASSERTION）。
- **Umi-OCR / OBS 都 MIT/GPL**：自己用没问题；OBS 是 GPL-2.0，二次分发要遵守。
- **Oink 走局域网直连**：默认信任同网段设备，公共 Wi-Fi 下建议关掉自动配对。

## 采集类工具的边界（MediaCrawler）

- **平台条款**几乎都禁止自动化采集，被封 IP/账号很常见；
- 采集到的**用户评论属于个人信息**，二次使用/公开要过《个人信息保护法》；
- 它的许可证是 **NOASSERTION**，商用前自己读 LICENSE；
- 只采公开内容、控制频率、不存个人身份信息，是三条基本底线。

## 游戏自动化：能做，但会封号

`BetterGI`（原神）和 `March7thAssistant`（崩铁）都是**模拟键鼠+图像识别**的全自动挂机工具：

- **明确违反游戏用户协议**，米哈游对第三方自动化有封号先例（尤其长时间挂机、异常操作特征）；
- 用**小号**试，别拿主号；
- 它们需要屏幕常亮 + 前台权限，笔记本长期跑注意散热；
- 两款都 GPL-3.0，代码可读，但"开源"不等于"官方允许"。

## LibreTV 与 TVBox 是同一类风险

`LibreTV` 是"自建影视站"方案：一条命令部署，聚合全网公开采集源。**和 TVBox 一样，播放源基本都是未授权影视**——
在国内，提供或使用这类聚合源存在著作权风险，站点公开可访问时风险更高。仅作技术研究，别公开传播。

## 电视瘦身（CleanYourTV）注意

- **要开 ADB 调试并从电脑装**，等于把电视的控制权交给命令行；操作前记下原包名清单，删错可能进不去系统；
- 卸载预装组件**可能影响厂商保修**，部分电视升级后会被推回；
- 它不 root，所以是"可逆"的，但**恢复要靠你自己记的清单**。

## 用之前要知道的

- **RustDesk 是 AGPL-3.0**：自建服务器给自己用没问题，但对外提供远程桌面服务要按 AGPL 开源修改；没自建中继时走官方服务器，速度和稳定性受限。
- **Motrix 的许可证 GitHub 识别不出（NOASSERTION）**：商用前自己读 LICENSE。
- **Mole 是 GPL-3.0 的命令行工具**：删除类操作**先用 `--dry-run` 或预览模式**跑一遍，别一上来就清。
- **LocalSend 只在同一局域网直连**：跨网段用不了，这是设计如此（不经服务器）。
- **Concat 官网/下载**：<https://concat.standalones.org>
- **Concat 是 AGPL-3.0**：自己剪片没事；但如果你把它包进产品、或对外提供剪辑服务，就要按 AGPL 开源你的修改。
- **它自己标了 Beta**（README 第一行就是 `Beta:`）：重要项目别把素材库押在它上面，先把工程导出备份。
- **它有 voice-cloning 相关能力**：克隆他人声音必须拿到授权，冒充/诈骗是违法的，平台也会封。
- **gods-eye-view 的许可证是 NOASSERTION**：GitHub 认不出，商用前必须自己读 LICENSE；它聚合的公开卫星/摄像头数据**各源有自己的条款**，二次分发前逐条确认，也别拿来做追踪个人的事。
- **DBX 连生产库请用只读账号**；确认它把凭据存在哪（本地加密还是明文）。
- **Scrapling 能力越强越要自律**：先看目标站 `robots.txt` 与用户协议、限速，别把人家打挂。
- **agent-desktop 等于把桌面控制权交给模型**：先在虚拟机或小号环境试。
- IT-Tools 是 **GPL-3.0**：自己用没事，改了分发要开源。

## 在线即用 vs 自托管

- 纯前端（IT-Tools、CyberChef）→ 数据不出本机，最安全
- 需要后端（Stirling-PDF、DBX、Scrapling）→ 自托管时记得加认证，别裸奔到公网
