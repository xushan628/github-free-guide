1. 本站是什么

本站把抖音等公开渠道里提到的开源项目，核实仓库地址、许可证与用途后，按「你想干什么」分类整理成一份导航。 每个条目只包含：项目名称、开源许可证、官方仓库链接、以及跳转到该项目 Releases 页的下载入口。

2. 本站不做什么

  • 不托管任何代码或二进制包——点击「⬇︎」是直接跳转到该项目在 GitHub 的 Releases 页面；
  • 不提供镜像、网盘转载或代下载；
  • 不修改、不重新打包原作者发布的任何文件；
  • 不代表任何项目官方，与仓库作者无隶属或合作关系。

3. 版权与许可证

各项目的版权归其作者所有，使用条件以其仓库中的 LICENSE 为准。常见情况：

  • MIT / Apache-2.0 / BSD：可商用，但需保留版权声明与许可文本；
  • GPL / AGPL：二次分发与网络服务有开源义务，改动后须提供源码；
  • 无 LICENSE / NOASSERTION：默认「保留所有权利」或条款不明，请勿再分发或商用；
  • 站内文字说明为本站撰写，属转述与评论，引用原文的段落均已注明来源。

4. 风险提示

部分项目处在灰色地带，站内已单独标注，但仍需自行判断：

  • 涉及影视聚合源、绕开平台限速、自动化操作第三方平台（爬虫/投递/闲鱼自动化）的项目，可能违反平台协议或涉及著作权问题；
  • 光猫提权、逆向工程类工具，仅限自有设备或已获授权的场景，用于他人系统可能构成违法；
  • 换脸、语音克隆类工具，未经本人同意制作他人音视频可能侵犯肖像权、声音权益。

本站只做记录与提示，不对使用者因使用这些项目造成的任何后果负责。

5. 数据来源与时效

星标数、许可证、最新版本号通过 GitHub 公开 API 获取，随时间变化；请以仓库实际页面为准。 外链有效性由自动化体检脚本定期检查，报告见 link-check.md。

如果你是某个项目的作者，认为本站的收录描述有误、或希望移除条目，请到 仓库 Issues 提一个 issue， 说明项目与理由，核实后会在 48 小时内移除或修改。
